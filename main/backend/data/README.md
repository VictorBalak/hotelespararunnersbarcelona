# Datos del backend

Esta carpeta contiene los datasets más importantes. El mapa lee desde aquí a traves de los endpoints de `mapapp`.

## Archivos principales

- `barcelona_hotels_location.geojson`: ubicaciones de hoteles y campos de accesibilidad runner.
- `barcelona_routes_location.geojson`: rutas de running usadas para el mapa y para calcular cercania.
- `barcelona_hotels_enriched.geojson`: hoteles enriquecidos con Booking, valoraciones y resumen de reseñas.
- `barcelona_hotels_list.xlsx`: metadatos de hoteles.
- `barcelona_hotels_reviews.xlsx`: reviews y valoraciones por hotel de Booking.
